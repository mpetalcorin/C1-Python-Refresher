## Key Learnings

Why Python Matters

Python’s readability and flexibility make it a favorite in data science, AI, and web development. Originally created by Guido van Rossum (van Rossum, 1991), Python’s philosophy of simplicity makes even complex workflows approachable.

## Jupyter Notebooks

Using Jupyter, I experienced the magic of interactive programming—where code, output, and narrative live side-by-side. It’s like a digital lab notebook. As Kluyver et al. (2016) explained, it’s become a gold standard in reproducible scientific workflows.

## Data Types & Structures

Understanding integers, floats, strings, and booleans gave me insight into how Python handles information. Structures like lists, tuples, and dictionaries helped me organize data like tools in a toolbox.

## Functions, Loops, and Conditionals

I reinforced concepts like:
	•	Functions as reusable code blocks (Parnas, 1972)
	•	Conditionals to control program flow
	•	Loops for repetition—both for and while

## NumPy

With NumPy (Oliphant, 2006), I learned how to perform fast, vectorized math using arrays. It’s like switching from a bicycle to a jet engine for numeric computing.

## pandas

pandas (McKinney, 2012) changed how I think about data. With Series and DataFrames, I could slice, filter, and group data just like in Excel—but with code.
